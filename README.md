A portfolio-level dashboard demonstrating Project Controls reporting for real estate/construction: budget vs. actual cost, SPI/CPI performance tracking, schedule variance, and a risk register with severity/probability heatmapping. Built on synthetic data modeling a 28-project portfolio across sectors like residential towers, mixed-use, and infrastructure.
